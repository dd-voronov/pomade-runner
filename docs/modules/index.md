# Modules

A module is a real area of Runner with a home in the code. Tickets name one in `module:`
(`../Pomade/docs/process/backlog.md`); process and project-management items use `meta`. A new area
gets its row here first.

| Module | Covers | Where in code |
|---|---|---|
| `keeper` | Runner's side of the keeper (`pomade-kit/keeper`): its entry, starting and owning it from the scheduler, run and service sessions, per-run output logs, header actions, service supervision, process priority | `src/keeper/` (the entry `entry.ts`; the scheduler's hold on the keeper in `sessions.ts`; session and run ids in `ids.ts`; the keeper's version in `version.ts`; a service as a session in `services.ts`; service supervision in `supervisor.ts`, its port and URL checks in `readiness.ts`; the shared model of sessions and services in `model.ts`); the build ships the keeper's run-time packages (`scripts/build.mjs`) |
| `scheduler` | the always-on backend (login item): triggers (schedules, hooks, chains), missed-run policies, the start queue and load control, the run lifecycle, history and captured output, Needs you, the workspace settings | `src/scheduler/` (entry `main.ts`, wiring in `scheduler.ts`; when a schedule fires in `triggers.ts`; which jobs an event fires in `hooks.ts`; which jobs a finished run fires in `chains.ts`; the loop safety net in `loop-guard.ts`; what a missed-run policy makes of missed runs, and Run at…'s time, in `missed.ts`; the queue — the switch, the warm-up, the slots — in `queue.ts`; the switch's position in `switch.ts`; the run lifecycle — the look, wake, overlap, the staged start, the login hook, firing hooks and chains, time limits, long-run warnings — in `runs.ts`; a git run's command line, its end read with `pomade-git`'s result, its lines per repo and the `jobs.forRepo` answer in `git-runs.ts`; history and output in `history.ts`; Needs you and the notices runs make in `needs-you.ts`; the settings file in `settings.ts` (pure) and `settings-file.ts` (read and written); Pomade's projects as last heard in `projects.ts`; the shared model of runs in `model.ts`; the test clock in `clock.ts`; the command's control protocol in `control/`) |
| `jobs` | the job file format, loading and watching the jobs folder, validation, the `pomade-runner` command, the agent skill | `src/jobs/` (the validator, chain loops included, in `check.ts`; a job's trigger in words in `words.ts`; the command in `cli/`, skill linking in `skill/`); the skill's master copy in `app/skills/pomade-runner-jobs/` |
| `ui` | the side panel, the Runner tab (Jobs · History · Services · Settings), the job form, result cards, the help tooltips | `src/ui/` (the design tokens in `tokens.css`, light only; the shared primitives in `kit/`; the two frames' layouts in `shell/` — the tab shell and the panel shell; every help text in `help.ts`; Runner's API, live, the workspace's repos (`git.read`), Pomade's projects and the tab's route in `useRunnerApi.ts`; the panel in `Panel.tsx` — Needs you in `NeedsYou.tsx`, Running now in `RunningNow.tsx`, Next up in `NextUp.tsx`, their words in `panelWords.ts`; the Runner tab in `RunnerTab.tsx` — the Jobs view in `JobsView.tsx` with its cells' words in `jobWords.ts`, the Services view in `ServicesView.tsx` with a service's look in `serviceWords.ts`, History in `HistoryView.tsx`, a run's look in `runLook.ts`, the result card in `RunCard.tsx`, Run at…'s field in `RunAtField.tsx`, a run's output page in `OutputPage.tsx`, the Delete confirm in `DeleteJobDialog.tsx`; the job form in `form/` — its state in `state.ts`, the kinds in `kinds.tsx`, the trigger section in `TriggerSection.tsx`, the schedule editor's logic in `schedule.ts`, the policies sentence in `policies.ts`, the form's job-file writes in `jobFiles.ts`; stand-ins until their slice: the switch in `SwitchControl.tsx`, the Settings view in `SettingsView.tsx`) |
| `integrations` | everything that crosses the app boundary: agent jobs (`pomade-agents`), git jobs (`pomade-git`), platform events and notifications, Runner's published API and events, native macOS notifications | `src/integrations/` (Runner's API names, checks, events and tab routes in `runner-api.ts`; the connection to Pomade and the API it serves — `jobs.forRepo` to Pomade's Git panel included — in `pomade.ts`; notices and the badge in `notices.ts`) |
| `meta` | process, docs, repo setup | `app/` (manifest, icon), `scripts/`, `install`, `e2e/`, the configs at the root; shared by every module: `src/app.ts`, `src/locations.ts` (Runner's state folder, and where `pomade-git` is) |
